# MTM Content Toolkit

أدوات محتوى MTM — برومبتات جاهزة، مولّد تقويم آلي، ودليل مرجعي.
مبني من ملف `MTM_مكتبة_المعرفة_والأفكار.md`.

---

## وش في كل مجلد

| المجلد | المحتوى |

| `prompts/` | البرومبتات السبعة، كل واحد بملف مستقل جاهز للنسخ في Claude.ai |

## تشغيل مولّد التقويم

### مرة واحدة — التجهيز

```bash
cd mtm-content-toolkit
python3 -m venv .venv
source .venv/bin/activate          # على ويندوز:  .venv\Scripts\activate
pip install -r requirements.txt
```

### كل مرة — المفتاح

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

اكتبه في الطرفية فقط. **لا تكتبه في أي ملف داخل المشروع** — ولا حتى في ملف
`.env`. لو انرفع المفتاح للمستودع مرة، اعتبره محروقاً وأنشئ غيره.

### التشغيل

```bash
python3 calendar/generate_calendar.py                # تقويم 30 يوم
python3 calendar/generate_calendar.py --hooks-only   # 50 هوك
```

الناتج يُحفظ في `calendar/output/` باسم يتضمن التاريخ والوقت، بترميز يفتح
العربي صح مباشرة في Excel.

### الخيارات

| الخيار | الوظيفة |
|---|---|
| `--hooks-only` | يولّد الهوكات بدل التقويم |
| `--model` | تغيير الموديل (الافتراضي `claude-opus-5`) |
| `--effort` | عمق التفكير: `low` / `medium` / `high` / `xhigh` / `max` |

تقدر كذلك تثبّت الموديل عبر متغير البيئة `MTM_MODEL` بدل كتابته كل مرة.

### أي موديل أختار؟

| الموديل | متى |
|---|---|
| `claude-fable-5` | أعلى جودة ممكنة، والوقت والتكلفة مو مشكلة |
| `claude-opus-5` | **الافتراضي** — أفضل توازن للمحتوى الإبداعي |
| `claude-sonnet-5` | أسرع وأرخص، جودة قريبة |
| `claude-haiku-4-5` | تجارب سريعة فقط — مو مناسب للمحتوى النهائي |

السكريبت يعدّل شكل الطلب تلقائياً حسب الموديل، فما تحتاج تغيّر أي كود.

## بعد التوليد — الخطوة اللي ما تنفع تتخطاها

**الناتج هيكل، مو محتوى جاهز للنشر.** Claude يعطيك البنية والزوايا، وأنت تضيف:

1. **القصة الحقيقية** — من ورشتك، من عميل فعلي، من خطأ صار معك. هذا الشي الوحيد
   اللي ما يقدر أي مولّد يجيبه.
2. **اللهجة** — عدّل الصياغة لتصير بصوتك أنت، مو بصوت نموذج لغوي.
3. **الصور الفعلية** — أي يوم في التقويم ما له مادة بصرية موجودة، أجّله أو احذفه.
4. **مراجعة `docs/playbook.md`** — خصوصاً قاعدة الندرة الصادقة: أي رقم تنشره لازم
   يطابق واقع الإنتاج هذا الشهر.

خذ التقويم كمسودة شهرية، وراجع كل صف قبل ما ينزل.
