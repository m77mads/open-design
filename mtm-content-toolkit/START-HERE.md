## الخطوة ١ — أكّد الأرقام الستة 🔴 الأهم

⏱ ٣٠ دقيقة · بدون كمبيوتر · **سوِّها قبل أي شي**

فيه ست معلومات عن منتجك **غير مؤكدة**، ومكتوب في كل برومبت "ممنوع ذكرها". يعني
كل محتوى تولّده الآن يتجنّبها. تأكيدها يفتح لك محاور تسويقية مقفلة.

| # | المعلومة | من وين تعرف الجواب | وش ينفتح لك |
|---|---|---|---|
| ١ | **عدد القطع لكل إصدار** | سجل الإنتاج أو المورد | 🔥 **ندرة الكمية** — أقوى أداة بيعية لبراند بإصدارات محدودة، وهي الآن ممنوعة عليك تماماً |
| ٢ | مدة التصنيع | المصنع | محتوى "ليش تنتظر" + رد على سؤال التسليم |
| ٣ | الضمان | عقد المورد — الصفحة تقول **سنتان** لا خمس | يحسم تناقضاً قائماً في مستنداتك |
| ٤ | التخصيص (نقش اسم؟ مقاس ثاني؟) | قدرتك الفعلية | يحسم رد "أبي أنقش اسمي" |
| ٥ | سعر ١٢٠٠ | — | **مؤكد أنه خطأ.** كتالوجك يقول ٢,٢٠٠–٢,٣٨٠ ر.س |
| ٦ | هامش القهوة ٦٠٪ | بعد تسعير المورد | مؤجل — مو أولوية |

### كيف تكتب الجواب

افتح `brand/catalog.json`. لكل معلومة تأكدها سوِّ شيئين:

**أ) أضفها في `policies`** (أي اسم حقل تختاره):

```json
"policies": {
  "warranty": "ضمان المصنع سنتان على حركة الساعة",
  "returns": "إرجاع خلال 14 يوماً من الاستلام في حال وجود عيب مصنعي",
  "shipping": "توصيل مجاني وآمن لجميع دول مجلس التعاون",
  "vat": "الأسعار شاملة ضريبة القيمة المضافة",
  "packaging": "علبة خشبية فاخرة مبطنة بالجلد",
  "edition_size": "50 قطعة فقط لكل إصدار"
}
```

**ب) احذف سطرها من `needs_confirmation`** في آخر الملف.

ثم:

```bash
python3 brand/sync.py
```

✅ **خلصت لما:** يطبع "تم تحديث ٧ ملف" — يعني الحقيقة الجديدة انتشرت للبرومبتات
السبعة، والمنع اختفى منها.

> **جرّبتها فعلياً:** أضفت `edition_size` وحذفت البند → ظهر الرقم في البرومبتات
> واختفى المنع. الحلقة تشتغل.

## الخطوة ٢ — أول تقويم حقيقي

⏱ ٢٠ دقيقة (أول مرة) · ٣ دقائق بعدها

### مرة واحدة — التجهيز

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### المفتاح

روح `console.anthropic.com` → **API Keys** → أنشئ مفتاحاً، ثم:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

اكتبه في الطرفية فقط. **لا تحطه في أي ملف داخل المشروع.**

### شغّل

```bash
python3 calendar/generate_calendar.py
```

يطلع ملف CSV في `calendar/output/` باسم فيه التاريخ، يفتح في Excel بعربي سليم.

### 🔴 قاعدة المراجعة — لا تتخطاها

الناتج **مسودة**. افتح الـCSV واحذف أو عدّل:

1. أي يوم فكرته عامة ("انشر كواليس") — استبدلها بشي محدد أو احذف اليوم
2. **أي يوم ما عندك له صورة أو فيديو موجود فعلاً** — أجّله. اليوم بلا مادة بصرية
   ما ينشر
3. أي رقم ندرة ما يطابق واقعك هذا الشهر

✅ **خلصت لما:** يبقى عندك ١٥–٢٠ يوماً تقدر تنفّذها فعلاً. عشرون يوماً حقيقية
أفضل من ثلاثين وهمية.

```
بداية الشهر  →  python3 calendar/generate_calendar.py  →  راجع واحذف
منتصف الشهر  →  برومبت ٣ (تحليل الحساب)  →  نفّذ توصية واحدة
آخر الشهر    →  python3 calendar/generate_calendar.py --hooks-only  →  جدّد الهوكات
أي تغيير سعر →  عدّل catalog.json  →  python3 brand/sync.py
```

## قواعد لا تُكسر

1. **أي معلومة تنشرها لازم تكون في `catalog.json`.** لو مو موجودة، لا تنشرها.
2. **لا تعدّل الكتل المولّدة يدوياً** (بين `=== سياق البراند ===`) — أول مزامنة
   تمسحها. عدّل الكتالوج.
3. **لا تنسب معلماً لإصدار غير إصداره.** بوابة الكويت ما تنفع لمحتوى قطر.
4. **الأرقام الموسومة `[صناعة]`** في `watch-education.md` عن الصناعة عموماً — لا
   تنسبها لـMTM.
5. **الإنسان يقفل الصفقة.** الرد الآلي يفتح المحادثة فقط.
